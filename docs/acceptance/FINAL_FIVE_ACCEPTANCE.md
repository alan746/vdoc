# Final acceptance worksheet

Use one source revision for joint acceptance. Historical records and machine-readable ledgers remain evidence references rather than current pass claims.

| Category | Procedure | Artifact |
| --- | --- | --- |
| Native input | Real candidates in title, body, search, and dialogs | Input method, actions, backup, and screenshots |
| Printing | Unchanged source at required scales, every page inspected | JSON/PDF pairs, settings, counts, and review |
| Delivery | Actual downloads and reopening | Bytes, hashes, contents, and conversion differences |
| Storage | Termination and quota failure in isolation | Before/after backups, failure, recovery, and timing |
| Joint sign-off | Complete workflow and checks on one candidate | Revision, results, index, and unresolved cases |

Passed cases apply to their stated sample, browser, platform, and revision. Missing evidence stays pending. Separate preview from output, conversion from native delivery, and mock storage from real recovery.

Multilingual extraction needs exact whole-text comparison, selection, search, and independent readers. Visual correctness does not establish a correct text layer.

See [native procedures](../NATIVE_ACCEPTANCE_RUNBOOK.md), [validation](../VALIDATION.md), and [evidence](../QA_EVIDENCE.md). Preserve raw fixture and manifest data for new runs.
