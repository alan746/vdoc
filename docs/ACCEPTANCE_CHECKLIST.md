# VDoc 逐级、逐行验收清单

更新：2026-10-03。本表包含首页／文件夹、编辑器和 UI 细节。仅对照个人文档工作流；协作、共享、账号、多人同步不计入范围。**本表不是“全部通过”证明，第一阶段仍未最终验收。**

状态：**通过**＝这一行列明的用例和证据通过，不外推其他平台；**部分**＝有已验证能力，但仍有具体缺口；**待验**＝已有实现但尚无足够实测；**未实现**＝明确功能缺失；**受阻**＝当前环境无法取得证据。旧轮次通过与本轮实测分开标注。

对照来源：[Google 文件创建与命名](https://support.google.com/docs/answer/49114?hl=en)、[文件夹整理](https://support.google.com/drive/answer/2375091?co=GENIE.Platform%3DDesktop&hl=en)、[列表与网格视图](https://support.google.com/drive/answer/2375177?hl=en)、[版本历史](https://support.google.com/docs/answer/190843?hl=en)。这些是功能依据；没有把 Google 页面的排版、配色或品牌素材复制到 VDoc。
