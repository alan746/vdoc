# Google Docs 单人、本地编辑能力对照

更新：2026-10-03（第六十一轮）。范围仅含一个人在本机完成文档的能力。共享、评论协作、多人同步、权限、账号和跨设备同步不属于本次需求，也不计入差距。

2026-10-04范围调整：用户确认先稳定并验收核心底座，再进入AI。本表继续记录完整产品差距，但高级缺项不再全部作为AI前置门槛；当前执行顺序和通过标准以 [核心验收总表](ACCEPTANCE_GATE.md) 为准。未完成项保持未完成，不因后置而记为通过。

核心收尾第二轮：补文件选择入口JSON/DOCX重导入、损坏文件保护、有效图片Word独立渲染，以及500段真实键盘/滚动/局部响应测量；修复搜索不滚动与替换抢焦点，Word默认字体/标题样式不再继承Office蓝色主题。系统中文候选窗和浏览器PDF成品仍待验。旧微型PNG样本有CRC错误，历史“保留图片字节/尺寸”不得外推为图像成品通过。此为本地补验，没有重新进行Google官方功能对照。

## 结论

VDoc 已有可用的本地编辑底座，并补齐了一批原本缺失的日常能力。它仍不等于 Google Docs 的全部单人功能。尤其是分页排版、复杂 Office 文件保真和高级对象编辑，不能用已有工具栏或一次测试通过来代替验收。

本次对照依据 Google 官方功能说明与 VDoc 代码、集成测试、真实浏览器操作；没有登录 Google Docs 做逐动作、逐毫秒的 A/B 测试，此前未给“完成百分比”；2026-10-03应用户要求给出的粗略产品覆盖估算见文末，不作为验收分数。“顺滑”目前有功能检查与操作层性能数据，尚无完整浏览器输入延迟分位数基准。

## 本次修复的具体问题

- 增加文字删除、替换、全文替换、块移动、矩形单元格定位；统一参数验证与原子撤销。
- 修复连续事务读取旧选区、表格最后一行／列不能删、重复设置颜色／属性误报失败。
- 表格补齐右键菜单、属性面板、普通单元格细分、排序与移动。
- 普通 localStorage 不适合大文档；已迁移 IndexedDB，保留旧数据，并阻止切换后的迟到保存覆盖其他文档。
- 修复旧文档无 ID 时重复归档；增加本地库和保存版本。
- 修复 Word 直接格式丢失；避免把显式关闭的表头标记当成表头。
- 修复图片缩放手柄不可见，以及图片撤销后数据已恢复、画面尺寸却未更新的问题。
- 降低稳定块 ID 维护对普通文本输入的开销，避免每次文字／mark 修改都扫描全部块。

## 后续单人功能的实现次序

1. **保存与交付验收**：持续输入最长等待保护已于第四十八轮完成，仍需实机强退／存储异常检查；继续完成下载→重导入、系统IME、PDF逐页检查及大备份恢复，为浏览器输入／滚动建立基准。
2. **可编辑分页里程碑**：先确定分页与连续编辑模式共用的文档模型，再实现跨页输入／光标／选区／撤销和编辑中的重复表头，随后扩展页脚注、分节与分栏。行列拖动和只读分页重复表头已有实现，不再列为完全未开始。
3. **Office 往返保真**：建立固定 Word 样本文档集，逐项比较导入／导出／再导入的结构、格式与渲染；覆盖复杂表格、列表、图片、页眉页脚和脚注。
4. **高级写作对象**：图片裁剪／旋转／环绕、格式刷、样式库、书签与交叉引用、公式／文献、版本差异和更完整的语言辅助。
5. 本地编辑体验验收后再接文字指令，然后接长期语音、打断和异步目标版本保护。没有把多人功能排进来。
