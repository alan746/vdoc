# Personal editing capability comparison

This comparison concerns personal document workflows. It does not claim full compatibility with Google Docs or a feature-completion percentage.

| Area | VDoc support | Remaining limits |
| --- | --- | --- |
| Library | Folders, search, sorting, copies, favorites, trash, and restore | No complete team administration workflow |
| Saving | Local autosave, cloud documents, and named versions | Browser storage durability; no full revision-diff interface |
| Rich text | Common formatting, headings, lists, paragraph controls, and links | Smaller font and style catalog |
| Tables | Structure, spans, dimensions, borders, sorting, pinning, and RTL | Floating layouts, wrapping, and complex nested pagination |
| Objects | Images, alt text, footnotes, and table of contents | Advanced drawing, equations, citations, and object layout |
| Files | JSON, DOCX, HTML, TXT, and PDF workflows | Complex Office fidelity and multilingual extraction remain case-dependent |
| Languages | Language tags, Unicode search/counts, and direction | Native input methods and browser dictionaries vary |
| Voice | Authenticated operations, progress, and undo | Deployment and live acceptance remain separate from fixtures |

## Method

Use documented capabilities and repeatable cases. Distinguish missing implementation from missing platform evidence. A shared menu label or one passing example does not establish visual or latency equivalence.
